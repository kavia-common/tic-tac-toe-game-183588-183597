# Ocean Professional Theme Notes

This Flutter app uses the "Ocean Professional" theme:
- Primary: #2563EB (Blue)
- Secondary/Accent: #F59E0B (Amber)
- Error: #EF4444
- Surface: #FFFFFF
- Scaffold: #F9FAFB
- Text: #111827

UI Composition:
- Status bar with current turn/result and Reset action.
- Centered 3x3 board with smooth transitions.
- Subtle gradients, rounded corners, and light shadows.

Gameplay:
- Alternating turns (X starts).
- Win and draw detection.
- Reset restores initial state.
